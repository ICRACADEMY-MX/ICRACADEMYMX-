Criterios de aprobación

Requisitos para obtener la certificación

Para obtener CERA®, el participante deberá:

  • Completar los módulos de estudio.
  • Aprobar las evaluaciones correspondientes.
  • Obtener una calificación mínima de 80%.
  • Aprobar el examen final.
  • Presentar y aprobar el caso práctico.
